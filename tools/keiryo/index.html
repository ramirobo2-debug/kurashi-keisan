大さじ・小さじ・カップ・合の換算

量と単位を入れると、mL・L・大さじ・小さじ・カップ・合・升・勺に換算した値を並べて表示します。入力は端末の中だけで計算し、どこにも送信しません。

量と単位を入力

量は0〜100万、小数第3位まで。表示時だけ四捨五入し、末尾の0は省きます。料理用カップは200mL、米の計量カップは1合(尺貫法の1合 約180.39mLで計算。市販の米用カップはふつう180mL)です。米1合は約150g が目安。材料で密度が違うため、重さへの換算はしません。

換算の決まり: 1cc = 1mL、大さじ1 = 15mL、小さじ1 = 5mL、1カップ = 200mL。1升 = 2401/1331 L、1合 = 1/10升、1勺 = 1/10合。
