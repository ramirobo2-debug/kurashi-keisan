順列・組み合わせの計算

n と r を入れると、順列・組み合わせ・階乗などを表示します。入力は端末の中だけで計算し、どこにも送信しません。

個数を入力

0〜1000の整数。順列・組み合わせは r ≤ n のとき計算し、重複順列・重複組み合わせは r > n でも計算します。全角数字と3けた区切りのカンマに対応。重複組み合わせは n ≥ 1 が必要です。100けたを超える結果は先頭30けた・末尾30けたとけた数を表示し、途中式は r ≤ 10 の場合に表示します。

くわしい説明: 順列と組み合わせの違い・計算方法

関連するツール

  • 分数の計算・約分 — 分数と帯分数の四則演算、約分と通分の途中式
  • 等差数列・等比数列の和 — 初項・公差(公比)・項数から第n項と和。1から100までの和は5050
