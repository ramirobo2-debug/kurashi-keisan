方程式の計算(連立・二次)

方程式の係数を入れると解・途中式・小数の近似を表示します。入力は端末の中だけで計算し、どこにも送信しません。

係数を入力

a1x + b1y = c1

a2x + b2y = c2

ax² + bx + c = 0

整数・小数・分数(3/4)、全角数字、3けた区切りのカンマに対応。約分後の分子の絶対値と分母は1000000以下です。使わない係数にも0を入力してください。小数は第5位を四捨五入して第4位まで表示します。

くわしい説明: 加減法・判別式と解の公式

関連するツール

  • 平方根・累乗の計算 — √の値と簡単にした形(√12=2√3)、累乗・立方根
  • 分数の計算・約分 — 分数と帯分数の四則演算、約分と通分の途中式
  • 素因数分解・最大公約数・最小公倍数 — 素因数分解と約数の一覧、最大公約数・最小公倍数
