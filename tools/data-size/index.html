データ容量の換算(GB・GiB)

容量と単位・通信速度を入れると、換算結果と転送時間を表示します。入力は端末の中だけで計算し、どこにも送信しません。

容量を入力

0以上、小数20桁まで、入力全体は100文字まで。全角数字・3桁区切りのカンマに対応します。通信速度は0より大きい値が必要です。結果は選んだ桁で四捨五入し、末尾の0を省きます。転送時間は1秒単位、1秒未満は小数第1位で四捨五入します。実際は通信環境などで速度が落ちるため、転送時間は目安です。

式: バイト数 = 容量 × 単位の倍率。KB系は1000倍ずつ、KiB系は1024倍ずつです。転送秒数 = バイト数 × 8 ÷ 通信速度(bit/s)。1Mbps = 1,000,000bit/s、1Gbps = 1,000,000,000bit/sです。
