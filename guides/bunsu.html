通分・約分と帯分数

このページでは、分数の足し算・引き算の通分、約分、かけ算・割り算、帯分数の直し方を説明します。分数の計算ツールで途中の式と答えを確認できます。

通分は分母をそろえること

足し算と引き算では分母の最小公倍数にそろえます。1/2 + 1/3 = 3/6 + 2/6 = 5/6。2/3 + 3/4 = 8/12 + 9/12 = 17/12です。1/3 − 1/2 = 2/6 − 3/6 = −1/6のように負になることもあります。

約分は最大公約数で割ること

分子と分母を同じ数で割っても値は変わりません。12と18の最大公約数は6なので、12/18 = (12÷6)/(18÷6) = 2/3です。「約分だけ」では割った最大公約数も表示します。分子が0なら0にまとめ、分母の負号は分子へ移します。

かけ算・割り算

かけ算は分子同士、分母同士をかけて約分します。2/3 × 3/4 = 6/12 = 1/2。割り算は割る分数の分子と分母を入れ替えた逆数をかけます。2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6。分母0と、0/5など0の分数による割り算は使えません。

帯分数と仮分数

帯分数は「整数部×分母＋分子」を新しい分子にします。1と1/2 = 3/2、2と2/3 = 8/3なので、その和は25/6 = 4と1/6です。仮分数からは分子を分母で割り、商を整数部、余りを分子にします。17/12 = 1と5/12です。負の帯分数は全体が負で、−1と1/2 = −3/2です。

小数の表示

割り切れる3/8は0.375、1/128は0.0078125とそのまま表示します。割り切れない1/3は0.333333…、1/6は0.166666…、2/3は0.666666…です。第7位以下を切り捨てるため四捨五入はしません。負の値も絶対値の第7位以下を省きます。正確な値は分数の答えで確認してください。

関連する計算

最大公約数・最小公倍数の理解には、整数を素数の積に分ける素因数分解も役立ちます。比を簡単にする計算も最大公約数を使います。比の計算ツールも利用できます。

よくある質問

1/2 + 1/3 はいくつですか?

5/6です。分母を2と3の最小公倍数の6にそろえて、3/6 + 2/6 = 5/6になります。

分数の割り算はどうしますか?

割る分数の分子と分母を入れ替えてかけます。2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6です。

帯分数はどう入力しますか?

「整数部」に整数、「分子」「分母」に残りを入れます。1と1/2なら、整数部1・分子1・分母2です。

入力は送信されますか?

端末の中だけで計算し、どこにも送信しません。
